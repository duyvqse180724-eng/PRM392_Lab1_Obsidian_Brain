## 1. Quy Trình Làm Việc Tiêu Chuẩn
- **Main / Master:** Nhánh ổn định, sẵn sàng triển khai sản phẩm.
- **Develop:** Nhánh tích hợp các tính năng mới trước khi phát hành.
- **Feature Branches:** Nhánh làm việc độc lập của từng kỹ sư phần mềm.
- **Pull Request & Code Review:** Đảm bảo chất lượng trước khi gộp mã nguồn.
