# 🎯 Ngôn Ngữ Lập Trình Dart (Dart Programming)

> **Chuyên đề:** Cốt lõi của Flutter Framework

## 1. Đặc Điểm Của Dart
Dart là ngôn ngữ lập trình hướng đối tượng, tối ưu hóa cho ứng dụng client:
- Hỗ trợ cả **AOT (Ahead-of-Time)** để biên dịch ra mã máy siêu nhanh và **JIT (Just-in-Time)** phục vụ tính năng Hot Reload trong [[02_Flutter_Framework]].
- Cung cấp mô hình lập trình hướng đối tượng vững chắc theo [[09_Object_Oriented_Programming]].
- Hỗ trợ Null Safety giúp giảm thiểu tối đa ngoại lệ crash runtime.
